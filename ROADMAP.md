# KnowTheMD Product Roadmap

## Milestone 1.0.0 — Production Core (Current)
- [x] Monorepo architecture (`@knowthemd/ui`, `@knowthemd/markdown-engine`, `@knowthemd/editor`, `apps/desktop`, `apps/mobile`, `apps/website`)
- [x] Official Liquid Glass & Glossy Blue Gradient design system based on `.MD` logo
- [x] CommonMark + GFM engine with KaTeX math and 25+ language syntax highlighting
- [x] Edit, Preview, and Split-screen synchronized views
- [x] Dedicated Reading Mode with typography customizer and reading progress bar
- [x] Hierarchical Outline / Table of Contents generator (H1-H6)
- [x] Document search & replace with regex, case-sensitivity, and match count
- [x] Export to PDF (with print styling), HTML, Clean Markdown, Plain Text
- [x] Local-first File System operations, drag-and-drop, autosave, crash recovery drafts
- [x] Mobile touch experience with bottom navigation and keyboard Markdown toolbar
- [x] Official showcase website (`knowthemd.com`) with OS detection, download cards, interactive docs, and SEO metadata
- [x] Comprehensive test suites (Unit, Integration, Security/XSS audit, 100MB stress benchmarks)

## Milestone 1.1.0 — Advanced Workspaces
- [ ] Multi-workspace graph view (Obsidian-style note linkage `[[wiki-links]]`)
- [ ] Bi-directional link backlinks explorer
- [ ] Audio/Voice note transcription to Markdown

## Milestone 1.2.0 — Extended Collaboration (Optional Self-Hosted)
- [ ] Optional end-to-end encrypted peer-to-peer live collaboration (WebRTC CRDT)
- [ ] Git versioning integration (commit, diff, history timeline)
- [ ] Custom CSS theme store
